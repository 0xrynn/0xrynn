## 🧭 How I Hunt

```text
1. Map      →  endpoints, roles, trust boundaries, data flows
2. Question →  "What if I replay this? Swap this ID? Skip this step?"
3. Prove    →  minimal, safe, reproducible PoC (no data destruction, no pivoting)
4. Report   →  root cause · impact · steps · remediation
```

**Bug classes I enjoy most**

- `IDOR / Broken Access Control` — object-level and function-level authorization gaps
- `Auth & Session` — token/nonce reuse, replayable handshakes, weak session binding
- `SSRF` — server-side request abuse and internal-reach impact
- `Crypto misuse` — unsalted hashes, predictable schemes, client-recoverable secrets
- `Smart-contract logic` — what the code *allows* vs. what the protocol *intends*

## 📂 Featured Project

### [🔍 Security-Log-Analyzer](https://github.com/0xrynn/Security-Log-Analyzer)

A lightweight Python tool that parses authentication logs to:

- detect repeated **failed login attempts** (brute-force indicators)
- summarize **per-IP activity**
- highlight **suspicious behavior** for quick triage

Built for learning and basic security monitoring: the defensive side of the same attacker mindset I use in research.
